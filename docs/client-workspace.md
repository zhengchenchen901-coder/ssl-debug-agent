# 客户端工作空间

客户端使用原生 HTML、CSS、JavaScript，资源随插件本地打包，不依赖前端框架或 CDN。

## 导航与操作位置

| 范围 | 位置 | 功能 |
| --- | --- | --- |
| 全局 | 连接实例 | 搜索、状态筛选、新建、导入，进入实例工作区 |
| 全局 | 实例行的更多菜单 | 配置导出、Worker 启停、配置重载、删除及工作台入口 |
| 全局 | 全局输出 | Manager 和未归属当前实例的 MCP 输出 |
| 全局 | 环境与管理 → 环境检查 | 环境报告、失败原因和修复提示 |
| 全局 | 环境与管理 → 管理员 | 注册及恢复管理员账号 |
| 全局 | 环境与管理 → Manager | 端口范围、Manager 关闭与 Manager 最终结果 |
| 实例 | 实例总览 | SSH/Worker 健康、运行事件、后端服务检查与启动 |

实例列表仅显示高频信息，详细运行信息放在实例总览的折叠区。列表不显示“默认”标签；配置中的默认实例 ID 只作为 Manager 元数据展示，多实例操作仍以明确的实例选择为准。

## 配置编辑

数据库连接分为自动业务连接、人工管理连接、沙盒管理连接，分别保存各自配置与用途。分组切换不会清除当前输入。

“保存配置”统一提交当前实例本次编辑的配置，沿用原有权限差异计算与保存接口。没有修改的白名单会保留。运行中的实例需要单独重新加载 Worker 配置。

隐藏分组中有不符合条件的必填字段时，保存会先切换到对应分组并定位字段。离开尚未保存的配置页会提示；保存期间阻止重复提交。口令输入在关闭编辑或保存后清空。

服务和日志的高级 JSON 配置保持原有语义：留空保留，`{}` 清空。写入、服务启动、沙盒账户配置及清理沿用既有明确目标、范围核验和确认流程。

## 管理员工作台

在实例总览点击“手动工作台”，通过独立本地端口登录管理员会话。人工认证不复用主面板令牌，切换界面不改变 SSH、MongoDB 或自动工具的授权范围。

工作台沿用同一套配色、字体、按钮和面板样式。数据库内分为“文档与索引”和“mongosh”，切换视图保留当前会话。SSH 与数据库操作保留实际目标和账号信息。

## 主题、窄屏与诊断

默认跟随系统明暗外观，右上角可切换。浏览器仅额外保存外观偏好，认证数据继续使用原有存储边界。窄屏下侧栏变为顶部导航，实例表按记录重排，设置表单改为单列。

诊断模式与离线报告直接进入环境检查，实例管理和管理员操作不可用。离线报告嵌入样式与所需脚本，无需启动 Manager。

源码的 `agent/public/` 是客户端资源来源；`npm run build:runtime` 将资源及静态路由白名单同步到仓库内 runtime，并更新资源哈希。构建不安装插件、不重启当前 Manager、不连接远端。
