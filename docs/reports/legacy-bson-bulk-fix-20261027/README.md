## 原因与修复

`__bulkUpdateSelector` 已把 `_id` 和 expected 原值解码为驱动原生 BSON；批量提交又对整个选择器调用 `__decode`。在 MongoDB 驱动 3.3.4 所用旧 BSON fallback 下，第二次递归解码把原生 ObjectId 的 Buffer 和原型拆成普通对象，BSON 序列化拒绝写入。小型字符串 ID 夹具没覆盖这一情况。

现去掉多余的选择器解码，保留逐字段解码、原前镜像检查、事务、幂等回执和回滚。未改变业务计划、金额、目标会员、配置或驱动版本。

这一路径已在 Node v20.20.2 + mongodb 3.3.4 + 一次性 MongoDB 4.4.30 副本集中用虚构 85 人、255 操作复现：修复前在 business_write 失败，堆栈位于 bson serializer.js:287；修复后相同结构事务提交、逐人余额/内嵌流水/独立流水/原记录标记检查、重复批次不二次加分和完整回滚均通过。这是本地复现与修复证据，真实任务修复后的提交仍未验证。
