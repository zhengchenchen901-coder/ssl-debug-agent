# 资源池重构与插件更新

日期：2026-10-18。真实环境并发验收将在独立 Codex 会话中执行，本报告不将本地验证等同于真实环境验收。

## 已完成

- Manager 按远端主机／显式资源域统一分配 CPU、内存和读入、处理、SSH 接收带宽预算；Worker 负责执行与反馈，业务任务不再自管实例资源池。
- 日志流使用通用远端节流运行时；MongoDB 批量任务在事务批次边界调整派发，已开始的事务不被强杀。
- 非批量和控制任务保留资源、SSH 通道；资源减少确认后才增发额度，Worker 失联后保留回收等待期。
- Dashboard 增加实例任务列表、批量任务手动最高档／恢复自动档、适用的暂停／恢复／取消和归档边界停止操作。资源域内只允许一个最高档任务。
- 区分请求额度、有效额度及可观测用量；普通命令仅做准入控制，MongoDB 做批次派发控制，不宣称对任意远端进程或 mongod 实施 OS 配额。
