# 日志目录关闭兼容性修复（2026-10-23）

修复版：`2.4.0+codex.20261023.2`。

## 问题与修复

`for await` 遍历 `fs.Dir` 时，迭代器负责在正常完成、`break` 或抛错时关闭目录。
原来的 `finally` 再次调用 `handle.close().catch(...)`。Node 12 对已经关闭的目录会同步抛出
`ERR_DIR_CLOSED`，发生在返回 Promise 之前，链式 `.catch()` 无法捕获；它还可能覆盖真实的读取错误或超时。

现在由迭代器统一负责关闭，不再重复关闭，也不统一吞掉错误。
真实目录读取和关闭错误继续报告，超时继续终止查询，扫描上限继续报告截断。
同步查询与后台查询共用同一份远端助手，因此同时受益。
