# 沙盒账户结构化配置与按实例密码

已新增 Dashboard 每实例沙盒密码字段与“保存并配置沙盒账户”，以及 prepare/configure 两个专用 MCP 工具。编辑时密码留空保留、不回显；本地文件权限保护复用已有 Unix/Windows ACL 实现。Worker 收到的配置哈希必须与 Manager 当前实例配置一致，密码变化会使旧计划失效。

准备检测所选实例的 MongoDB 版本、wire protocol、单机/复制集/分片类型和认证权限。执行前再次检测并校验环境和配置快照；不会使用其他实例的数据库、连接分组或密码。角色权限固定为专用库的技术集合；管理用户只能 find/remove。执行用户保留原角色并追加技术集合的执行/初始化权限。仅有匹配归属标记和角色定义的账户可重置密码，使用该实例最新保存值。既有账户/角色冲突停止，不执行降权或重置猜测。

账户、角色及文件配置不支持一个跨系统原子事务，因此结果可能部分完成。计划标记 started/partial 后不允许盲重放；重新准备会验证现有对象和配置，通过最新配置密码恢复未完成的连接配置写入，不读取备份中的凭据。执行会备份远端业务配置、只增加/更新管理连接分组，保留原业务分组和文件属主/属组，并将文件设为 0600；确认页面明确提示该权限变化。集合与 TTL 索引仍单独准备并确认。

- 隔离 `npm run diagnose`：识别 38 个工具，MCP 初始化和启动验证通过，未连接真实实例。
- 安装版本：2.3.0+codex.20261014；runtimeId 为 `2.3.0:ce1ae7a99da3a4c6be539bf9dda40d36b60bb6deb01634faa4fe8b4ee51ef701`，安装副本无 node_modules，manifest 文件哈希一致。

真实集成覆盖 MongoDB 4.4；版本与拓扑差异的单元验证包含 6.0 单机和拒绝 3.6。其他真实版本、Windows ACL 尚待相应环境实机验收。单机可管理账户不代表可执行依赖事务的批量业务写入。
