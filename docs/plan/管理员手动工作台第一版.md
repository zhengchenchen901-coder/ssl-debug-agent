# 管理员手动工作台第一版（2.4.0）

## 已实现范围

- Dashboard 管理员注册、通过系统认证恢复密码、实例行“手动操作”入口。
- 独立 loopback 端口和浏览器来源，管理员登录后展示连接预览、SSH 终端和操作面板。
- 每个人工终端使用独立 SSH 连接与 PTY；复用实例账号、私钥和主机指纹，不占用自动 Worker 的调度通道。
- 自由输入命令、交互式程序、Ctrl+C、窗口尺寸变化、清屏、断开及手动重连。
- 实例绑定、一次性票据、来源校验、输入/输出缓冲限制、会话撤销与无终端内容的审计。

数据库 GUI/数据库 shell、服务日志面板、Agent 建议、多终端和会话恢复属于后续版本。

## 本机认证与管理员

首次注册需要 dashboard 的本地 token 和操作系统认证。新增管理员另需已有管理员凭据。系统认证成功前不落盘管理员账号。

macOS 通过随包 Swift 源码构建本机 helper，调用 LocalAuthentication 的 deviceOwnerAuthentication；允许 Touch ID 或系统密码。首次使用需要 Xcode Command Line Tools，缺失时明确报错。helper 在私有目录缓存，按源码和架构区分；调用结果校验随机 nonce 和当前 UID。系统交互失败、取消、超时或证明不匹配均拒绝操作。

Windows 通过 PowerShell 调用原生 CredUI 凭据窗口和 LogonUser，核对验证身份的 SID 与插件进程用户一致。凭据只在原生认证进程内使用，不经过 Node/浏览器，也不保存。Linux 暂不可注册/恢复，不接受前端自报验证结果。

本机认证保护插件管理员身份创建/恢复，不提升服务器账号。最多十个本地管理员；所有管理员可选择已启用实例，人工登录时授权绑定具体实例。恢复密码会撤销该账号全部旧人工会话，并防止重置前开始的旧密码校验在重置后生成新会话。

密码使用 Node scrypt（N=32768、r=8、p=1、独立随机盐）保存哈希。账号文件与审计目录使用所有者专用权限，拒绝符号链接和硬链接文件。最多允许两个并发密码校验；五分钟内五次失败后暂停校验，避免暴力尝试。

## 接口和权限

Manager 以下接口继续要求现有本地 Bearer token 与 Host/Origin 校验，不新增 MCP 工具：

| 接口 | 功能 |
| --- | --- |
| GET /api/manual/status | 管理员数量与系统认证适配状态 |
| POST /api/manual/register | 系统认证后注册；已有账号时要求已有管理员凭据 |
| POST /api/manual/reset | 系统认证后重置已有管理员密码并撤销旧会话 |
| POST /api/manual/open | 为指定实例准备独立工作台并返回无凭据 URL |

工作台只监听 127.0.0.1 的系统分配端口，使用独立来源、无 CORS、无 Cookie；要求精确 Host，并对所有修改请求和 WebSocket 校验 Origin。浏览器窗口断开 opener；静态资产来自固定清单。

| 接口 | 功能 |
| --- | --- |
| POST /api/login | 管理员凭据换取绑定实例的内存 token |
| GET /api/session | 使用人工 token 检查当前会话与连接目标，不延长闲置期限 |
| POST /api/logout | 撤销当前人工会话并断开终端 |
| POST /api/terminal-ticket | 使用人工 token 获取十秒有效的一次性连接票据 |
| WebSocket /terminal | 精确路径；首条消息验证票据，然后才创建 SSH 连接 |

票据不出现在 URL 中，不能复用，也不能修改实例/SSH 参数。每个人工会话最多一个终端，共最多八个人工会话。未认证 WebSocket 五秒后关闭；客户端最大帧为 64 KiB。终端输出通过二进制帧送到 xterm，不作为 HTML 插入页面。输入按帧和速率限制；远端输入缓冲满后断开。xterm 完成数据处理后回传字节确认；未确认输出超过高水位时暂停 SSH 流，降到低水位后恢复，过量时终止连接，避免浏览器渲染较慢时无界积压。

人工 token 不能替代 Manager token，Manager/MCP token 也不能替代人工 token。自动 Worker 不提供这些人工终端接口。权限分离属于本地应用授权，不防御已控制本机用户账号的进程。

## 生命周期

人工会话十五分钟无键盘输入后失效，最长八小时；输出、心跳、窗口尺寸和状态轮询不延长输入闲置期限。有效会话为已有 Manager 生命周期注册短租约，最后一个人工会话撤销后释放。Manager 关闭时断开终端、关闭工作台端口并撤销所有会话。

实例编辑会立即撤销人工授权；每次请求、输入及周期检查也校验实例配置指纹，禁用、删除或配置改变后不沿用旧凭据。停止自动 Worker 不影响独立人工 SSH 连接。

连接失败不自动重连，不自动重放命令。用户主动重连会创建新 Shell。退出会关闭 SSH 连接，但不能保证终止用户已经通过 nohup、tmux、服务管理器等启动的后台任务，也不承诺任意终端操作可回滚。

## 验证方式

使用项目要求的 Node 22.18–22.x：

```sh
cd agent
npm ci
npm run build:runtime
npm test
npm run test:manual-browser
cd ../plugins/remote-debug-agent
npm test
npm run diagnose
```

浏览器集成测试使用临时 registry、临时管理员和本地 SSH 测试服务器，真实走浏览器、HTTP、WebSocket 和 SSH PTY；系统身份验证通过显式依赖注入模拟，不触发实际系统弹窗，也不连接生产环境。macOS 默认使用已安装的 Google Chrome；其他环境可设置 RDA_MANUAL_BROWSER_EXECUTABLE 指向可用 Chromium。截图默认写入 output/manual-workbench。

原生认证 helper 的编译/可用性检查与自动化浏览器测试分开。实际系统弹窗的成功、取消和 Windows 桌面策略兼容性仍需交互式实机验收，不能以模拟认证测试代替。插件缓存更新及运行中 Manager 的升级通过原有安装流程进行，不修改稳定的 MCP 启动和工具注册链路。
