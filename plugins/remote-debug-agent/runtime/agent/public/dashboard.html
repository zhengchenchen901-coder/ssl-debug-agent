MongoDB 写入权限

搜索不区分大小写，筛选不会清除已选集合。清空搜索可查看全部集合。

按住 Ctrl（Mac 使用 Command）可选择多项。集合选项来自所选数据库；集合白名单对所有所选数据库中的同名集合生效。已保存的名称会保留。
