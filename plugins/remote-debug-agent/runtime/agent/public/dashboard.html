MongoDB 自动业务连接配置

路径均为远程服务器上的绝对路径。配置分组为远程 JSON 文件中的分组名称，例如 production；URI 字段名为该分组中的连接地址字段，例如 url，支持 mongodb.url 这样的嵌套字段。

连接地址和凭据由实例读取远程配置文件。保存后，运行中的实例需点击“重新加载配置”生效，已停止的实例下次启动时生效。

人工数据库管理连接 · MongoDB

仅用于管理员手动工作台，独立于自动业务连接及沙盒管理连接。可复用远端配置文件和已有 profile；凭据由服务器读取，不在此填写。实际权限由数据库账户决定，保存后旧人工会话失效。shell 需要远端已有兼容的 mongosh，不自动安装。

MongoDB 写入权限

搜索不区分大小写，筛选不会清除已选集合。清空搜索可查看全部集合。

按住 Ctrl（Mac 使用 Command）可选择多项。集合选项来自所选数据库；集合白名单对所有所选数据库中的同名集合生效。已保存的名称会保留。

开启写入时需填写两项白名单。保存后，运行中的实例需点击“重新加载配置”；已停止的实例下次启动时生效。重新加载仅重启本地 Agent worker，不重启远端 PM2。实际写入仍需准备具体写入计划。
