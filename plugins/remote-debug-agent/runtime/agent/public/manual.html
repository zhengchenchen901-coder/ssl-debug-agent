永久终止任务

用于守卫失效或决定不再执行的任务。审核后永久关闭该任务的执行、恢复和回滚准入，保留历史记录与未知结果。后续业务需另行核对最新数据并准备新任务。


            
            
确认语句：我确认永久终止此任务，不再恢复或重试

            
            
            

            
此操作保留计划、回执和审计，不回滚积分或创建替代任务。远端记录未核验成功时会明确显示“本地已阻断，远端待核验”。

          

        

        

          

            
未知任务风险处置

            
原任务的历史结果仍为未知，可能存在已提交、已回滚或未观察到的修改。接受此风险可能导致重复补偿。机器无法确定的历史及在途结果交由您裁决；批准表示接受剩余风险，并授权关闭原任务后续调度及建立唯一关联替代任务。

            
            
            

            
            
            
确认语句：我接受历史结果未知的风险，并批准建立此替代任务

            
            

            
批准只允许随后建立这一份替代任务。本机将关闭原任务后续调度；此页面不会上传或执行补分；业务执行仍需核对准备结果及正常执行确认。
